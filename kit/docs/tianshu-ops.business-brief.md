## 1. 产品

- 产品名称：天枢 · 运营管理平台
- 一句话说明：「小豆盒」硬件 + 软件背后的内部 B 端运营中枢，协调「生产履约 → 广告变现 → 内容运营」全链路
- 服务的业务场景：设备收货→烧录发证→测试质检→入库出货的生产履约；广告聚合竞价计费的商业化；自营内容排期上下架的运营
- 当前阶段：**MVP**（PRD §10.3 期 1：L0 地基 + 三域正向主链最小闭环）
- 调性约束：内部 B 端，信息密度优先，中性调性，明确**不用**消费级温暖样式（PRD §一）

## 2. 用户与权限

| 角色 | 高频目标 | 权限边界 | 风险点 |
| --- | --- | --- | --- |
| 产线 / 质检 / 仓管 / 物流 | 推进设备生命周期各环节（烧录/测试/质检/出入库） | 仅生产履约域；操作受状态机驱动条件显隐 | 异常路径（烧录失败/返修/SN 冲突）误操作 |
| 商业化 / 广告运营 | 广告位/广告源/订单/投放/结算管理 | 仅广告变现域；金额字段按权限脱敏 | 资金结算、反作弊、身份隔离红线 |
| 市场 / 内容运营 | 素材/排期/上下架管理 | 仅内容运营域 | 误上架无回滚 |
| 平台管理员 | RBAC、审计、BI | 平台共享能力层 | 权限点粒度误配 |

- RBAC 两级：角色 role / 权限点 permission，权限点格式 `域:模块[:对象]:动作`（天枢 AGENTS.md，附录 A 为注册表）
- 无权限态三种处理已在 PRD §3.3 规范化（按钮置灰 + Tooltip / 403 占位页）

## 3. 核心流程

| 流程 | 入口 | 关键页面 | 成功标准 |
| --- | --- | --- | --- |
| 生产正向主链（第一优先） | 工作台 → 生产履约域 | 收货入库 → 烧录发证 → SN/证书 → 测试 → 质检 → 库存 → 出货 | 设备状态沿 §四状态机逐环推进，全程可追溯 |
| L0 全局地基 | 平台共享能力 | 账号与权限、审计日志 | 任何业务模块可鉴权、可留痕 |
| 广告正向链（第二批） | 广告变现域 | 广告位→广告源→广告主/订单→投放→竞价→计费→对账 | 供需接入齐备才能投放计费 |
| 内容正向链（第二批） | 内容运营域 | 素材库→内容位→排期→上下架→版本 | 内容就位才能排期上架 |

依赖顺序严格按 PRD §10.3：L0 → L1 三域主链 → L2 分析层；异常/逆向界面后置。

## 5. 数据与状态

| 实体 | 关键字段 | 状态枚举 | 异常状态 |
| --- | --- | --- | --- |
| 设备 | SN（主键）、固件版本、证书指纹 | PRD §四状态机（收货入场/烧录/测试/合格入库/出货…） | 烧录失败（重试/超限报废）、测试不合格（返修/降级/报废）、RMA |

## 7. 第三方底座（已决策）

- **antd v6（6.x，开源 MIT）+ ProComponents（MIT，开源免费，含 ProTable/ProForm/ProLayout）**，React 主线。依据：PRD 通篇按 Ant Design Pro 词汇写成（ProTable/ProForm/Tag 语义色/Transfer/Segmented），底座与 PRD 同源，转译成本最低；企业后台控件完备度最高。
- 版本事实（2026-07 核实）：开源最新版为 antd v6（当前 6.5.0），要求 React 18+；v6 默认纯 CSS Variables 主题模式，与 kit 的 token 映射天然契合；ProComponents 与 Ant Design 组织下所有项目均为 MIT，无付费墙。antd v6 官方另发布 `DESIGN.md`（ant.design/design.md）供 AI 工具理解其设计语言，可直接纳入 kit 的 AI 读取层。
- 契约不变：业务输出只从 `@ai-readable/kit` barrel import，antd 只作为 kit 内部实现底座（business-context-gate 原则）。
- 现有 21 个手搓组件按「器官移植」逐个替换内部实现，`rd-*` class 与 public API 保持，harness 当回归。
