# 交互控件组合

## 适用场景

- 短编辑和补充信息放进 `Drawer`，完整创建流程继续使用独立表单页。
- 日期、日期时间和时间值通过 `DatePicker` / `RangePicker` 传递字符串，业务层无需依赖日期库类型。
- 少量互斥选项用 `RadioGroup`，少量并列选项用 `CheckboxGroup`，单个开关状态用 `Switch`。
- 组织、分类等层级选项用 `TreeSelect`；普通扁平选项继续使用 `Select`。
- 文件选择用 `Upload`。组件只做类型、大小和数量校验，网络请求与结果状态由业务层处理。

## 选择值与执行命令

- `Select` 用于选择并保留值，`Dropdown` 用于命令集合。筛选条件与行内“更多操作”要能在触发前区分，外观沿用所选底座，不把“必须有边框”写成跨底座规则。
- 少量互斥值可平铺为 `RadioGroup`；`Switch` 只表达立即生效的二元状态，不因只有两个选项就强制使用开关。
- 长列表按查找任务考虑搜索、分组或分层选择；不把“2 项禁下拉”“10 项必须搜索”、某底座的弹层宽高推广为通用硬门。
- Tooltip 补充简短说明，不能承担必需的确认、表单或复杂交互；触屏与键盘须有可达的同等信息入口。选择弹层和命令菜单保留组件原有键盘、焦点与关闭行为。

来源：`<local-path-omitted>` 的 Select / Dropdown 区分、事实依据与原稿纠错。精确规格以冻结组件库和项目合同为准。

## 组合顺序

1. 先确定字段含义、必填条件和错误反馈。
2. 用业务字符串保存日期与选项值。
3. 上传文件进入业务回调后再启动导入、解析或保存请求。
4. 抽屉底部保持一个主操作；关闭、取消与保存后的焦点都回到触发点。

## 边界

- `Drawer` 默认禁止点击遮罩关闭，防止编辑内容意外丢失。
- `Upload` 不会自动上传，也不保存访问凭证或文件内容。
- 多选树返回字符串数组；单选树返回字符串或 `null`。
- 日期时间回调使用 `YYYY-MM-DDTHH:mm`，界面展示可使用更易读的空格格式。
- `RangePicker` 在两个输入间保留同一份编辑草稿；离开整个范围控件时才提交完整合法区间，半区间、逆序或禁用日期会回滚到上次已提交值。

## 验证

- 键盘可打开、操作并关闭 Drawer，焦点按预期返回。
- Drawer 与树选择弹层挂在当前 `.rd-root` 内；日期控件使用浏览器原生输入，不引入额外弹层运行时。
- 文件类型、大小和数量拒绝原因进入业务回调。
- 长文件名截短后仍能识别类型；完整名称可读取，不能用截短文本代替原始文件名提交。
- 组件的公开声明不暴露 antd、Dayjs 或上传适配器类型。
