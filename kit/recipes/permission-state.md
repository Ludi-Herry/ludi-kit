# Permission State

## 页面级 403

路由或整页资源无访问权限时使用 `ForbiddenState`。标题说明当前状态，描述写明缺失权限或申请路径，操作区只保留返回与申请权限等安全动作。

```tsx
<ForbiddenState
  description="当前账号缺少 platform:rbac:read 权限。请联系管理员申请，或返回工作台。"
  actions={<Button variant="outline">返回工作台</Button>}
/>
```

## 局部权限

- 单个操作无权限：按钮禁用，并让可聚焦的说明元素明确缺失权限点。
- 页面可读但不可编辑：保留内容，移除或禁用修改动作，页面头部标注“只读”。
- 列表无数据：使用空态，避免显示 403。

## 禁止

- 只显示大号 403，不给标题和下一步。
- 用红色表达权限，缺少可读文案。
- 用空态掩盖后端返回的 403。
