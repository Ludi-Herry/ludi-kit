# Layout Rules

## 页面结构

1. 应用框架：`AppShell`
2. 页面容器：`PageLayout`
3. 页面头部：`PageHeader` 或 `DetailHeader`
4. 业务模块：`FilterPanel`、`DataSection`、`FormSection`、`Card`

## 禁令

- 页面级标题不要放进 `Card` 或 `DataSection`。
- 不要卡片套卡片。
- 不要用一堆 margin 拼页面间距，优先用组件自带 spacing。
- 移动端先保持模块纵向堆叠，再处理局部密度。

## 可达与可读

- 移动端先确定用户任务；关系图与复杂图表按 [flow-diagram.md](./flow-diagram.md)、[data-visualization.md](./data-visualization.md) 重组，不只缩小桌面布局。
- 图标的视觉尺寸与可点击区域分开设计。扩大热区时核对相邻目标不重叠，键盘焦点、hover 与实际点击对象一致；触控尺寸按目标平台合同，不把 pt、dp 与 CSS px 直接等同。
- 正文与辅助文字保留项目字阶；用颜色、字重和间距建立层级，不能为了塞进更多信息无限缩字。长文案、长名称和字号放大后仍需核对操作可达。
- 图标与文字的中线、基线、光学对齐，以及阴影裁切的排查、脚本范围和证据格式，统一按 [visual-alignment.md](./visual-alignment.md)。涉及阴影、裁切容器或透明窗时执行其中的裁切审计。
- 嵌套圆角按内外间距检查光学同心，使用当前 Token；边框、选中描边与焦点环变化时不挤动相邻布局。静态示例的半径公式和线宽不能直接覆盖冻结规格。

## 已有国际化任务

仅在合同包含对应语言时检查：用长文案或伪本地化字符串核对弹性布局、截断与完整信息入口；泰语、越南语等变音符不被固定行高裁切。RTL 按阅读与操作语义调整方向，不能把图标、数字、图表与整个界面机械镜像。未声明国际化的页面不因本条增加翻译系统。

来源：`<local-path-omitted>` 的文字扩展、变音符和 RTL 段；不采用本期布局百分比作为固定参数。

来源：科普系列《图标点击热区》《大厂UI》提供视觉尺寸与交互尺寸、光学字重和图文对齐的案例；保留项目字阶、热区互不抢占和键盘一致性属于 Kit 本地验收约定，裁切沿用既有要求。口播中的 40px、28px、20dp 未直接设为统一门槛，具体材料定位见本轮审计记录。
