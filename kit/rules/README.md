# Rules

Rules define constraints that apply across pages. Read the matching rule after the project contract and component catalog, before choosing a recipe.

| Need | Rule |
| --- | --- |
| Choose, extend or add a component | [component-priority.md](./component-priority.md) |
| Build the page shell and spacing | [layout.md](./layout.md) |
| 走查图标与文字的中线 / 基线 / 光学对齐、阴影裁切 | [visual-alignment.md](./visual-alignment.md) |
| Choose SideNav, Tabs or Stepper | [information-architecture.md](./information-architecture.md) |
| Build a list or table | [data-table.md](./data-table.md) |
| Build a detail page | [detail-page.md](./detail-page.md) |
| Build a form | [form.md](./form.md) |
| Build a settings or configuration page | [settings.md](./settings.md) |
| Build a dashboard | [dashboard.md](./dashboard.md) |
| 选择图表、定义口径、联动与下钻 | [data-visualization.md](./data-visualization.md) |
| 绘制流程、状态、关系或拓扑图 | [flow-diagram.md](./flow-diagram.md) |
| Apply a theme | [theme.md](./theme.md) |
| Decide confirmation level, filter area, empty and zero values, data masking, row actions | [interaction-decisions.md](./interaction-decisions.md) |
| Review common failures | [anti-patterns.md](./anti-patterns.md) |
| Decide whether a difference between foundations must be unified | [foundation-differences.md](./foundation-differences.md) |

Rules express stable constraints. Task-specific assembly steps belong in [recipes](../recipes/README.md); exact component and Token values stay in their manifests.

需要外部设计或绘图方法时，读 [Skill 路由与边界](../docs/design-skill-routing.md)。已归纳规则随包提供，本机 Skill 和外置来源不是普通页面生成的强制依赖。
