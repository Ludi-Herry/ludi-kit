## 产品一句话

「小豆盒」硬件+软件背后的内部 B 端运营中枢，协调 生产履约 → 广告变现 → 内容运营 全链路。内部后台，信息密度优先，中性调性，不用消费级温暖样式。

## 全局信息架构（当前已实现子集）

```text
天枢运营管理平台（Ant Design Pro 左侧主菜单 + 顶部全局区）
├─ 工作台 /dashboard                    ← 第一批
├─ 生产履约域 /production
│  ├─ 收货入库 /production/inbound      ← 第一批
│  ├─ 烧录发证 /production/flashing     ← 第一批
│  ├─ SN/证书管理 /production/sn-cert   ← 第一批
│  ├─ 测试管理 /production/testing      ← 第二批
│  ├─ 质检管理 /production/qc           ← 第二批
│  ├─ 库存管理 /production/inventory    ← 第二批
│  ├─ 出货管理 /production/shipping     ← 第二批
│  ├─ 退货 RMA /production/rma          ← 逆向批次
│  └─ 固件版本管理 /production/firmware ← held-out 产品迭代
├─ 广告变现域
│  ├─ 投放计划 /ad/campaigns            ← 后续业务批次
│  └─ 对账管理 /ad/reconciliation       ← 后续业务批次
├─ 内容运营域
│  └─ 排期与发布 /content/schedule      ← 后续业务批次
```

依赖顺序依据 PRD §10.3：生产 L1 链 收货→烧录→SN/证书→**测试→质检→入库→出货**；RMA 使用独立逆向链回接测试、库存或报废终态。广告投放与对账、内容排期与发布分别保持业务域隔离。

## 设备生命周期状态机（PRD §四，单一事实来源）

```text
收货入场 → 烧录·发证 → 测试 → 合格入库 → 出货
             ↓失败(重试/超限报废)   ↓不合格(返修回测/降级/报废)   出货→RMA(返修/二次入库/报废)
```

当前页面覆盖生产正向主链、RMA 异常分支、固件版本维护、广告投放/对账和内容排期/发布；外部业务服务仍按页面中的能力提示保持未连接状态。

## 全局设计规范要点（PRD §3）

- **状态语义色（§3.1）**：success / processing / warning / error / default + 强调态 geekblue（已出货）/ cyan（二次入库）/ purple（灰度中）。颜色只承载语义；同一语义全平台同色。项目层映射见 `status-copy.md`。
- **非状态维度（§3.1.1）**：业务分类/优先级/业务域禁用语义色。业务域固定：生产=geekblue、广告=purple、内容=cyan、平台=default。
- **通用状态规范（§3.3)**：空态=Empty+一句话+主按钮；加载=骨架屏+行内局部 loading；无权限=按钮置灰+Tooltip 或 403 占位页；批量操作=底部浮条+危险操作二次确认。
- **硬隔离（§3.4）**：设备身份 ID（SN/证书指纹）与商业化标识 ID 界面上不并列、不可 join；广告与内容页面只使用各自业务标识。
- **术语（§3.5）**：SN=设备序列号（身份主键）；良率=合格数/投产数；角色 role / 权限点 permission 两级不混用。
- **权限点命名**：`域:模块[:对象]:动作`，域 ∈ production / ad / content / platform（天枢 AGENTS.md）。

### 固件版本管理验收

- **筛选**：固件版本号、机型、版本状态、签名状态；1440 px 桌面视口下四项筛选与查询、重置操作保持同一行。
- **9 列表格**：固件版本号、机型、版本状态、签名状态、灰度比例、绑定设备数、发布人、发布时间、操作；版本状态与签名状态使用独立语义标签。
- **Drawer**：新建固件版本从右侧 Drawer 完成，包含版本信息、发布说明、固件包三段；取消时恢复初始值并保持列表不变，保存草稿只更新本地演示状态。
- **ConfirmDialog**：回滚与停用进入危险操作二次确认，说明中带目标版本与绑定设备数；确认只进入审批演示状态。
- **精确行焦点**：取消 `v2.3.2-TJ-M1` 的回滚确认后，焦点必须回到该行刚刚触发对话框的“回滚”按钮，不能落到其他版本的同名操作。
- **权限与数据边界**：缺少 `production:firmware:view` 时进入 403；页面只使用演示数据，不上传真实固件、不调用 KMS、不连接生产 API。
