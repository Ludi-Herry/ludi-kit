# Promotion Draft: Deferred business flows need one public interaction foundation

- Feedback item: `fb-20260715-006`
- Status: `promoted`
- Target: `component`
- Action: `update-component`
- Destination: `components.manifest.json`
- Reviewer: `kit-maintainer`
- Reviewed at: `2026-07-15`

## Finding

RMA, advertising, reconciliation, and content scheduling repeat side editing, date ranges, choice groups, switches, file selection, and hierarchical selection that the public kit could not express.

## Proposed Change

Promote Drawer, DatePicker, RangePicker, RadioGroup, CheckboxGroup, Switch, Upload, and TreeSelect with domain-only props, provider-contained portals, accessible semantics, and no implicit network mutation.

## Evidence

- All four deferred pages need Drawer while preserving list context.
- Scheduling and reconciliation use date or date-range values in multiple flows.
- Uploads must remain local until business code starts a request, and organization or region choices need a hierarchy-aware control.
