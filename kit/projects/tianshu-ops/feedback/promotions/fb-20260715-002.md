# Promotion Draft: Selected table rows need a reusable batch action bar

- Feedback item: `fb-20260715-002`
- Status: `promoted`
- Target: `component`
- Action: `update-component`
- Destination: `components.manifest.json`
- Reviewer: `kit-maintainer`
- Reviewed at: `2026-07-15`

## Finding

Tianshu inventory and SA list pages enable row selection but keep batch actions in a static toolbar, so users cannot see the selected count, clear selection, or understand which records a dangerous action will affect.

## Proposed Change

Promote BulkActionBar and add backward-compatible controlled selection keys to DataGrid, while keeping mutation and confirmation logic in project pages composed with ConfirmDialog.

## Evidence

- The Tianshu inventory page has rowSelection plus batch freeze and unfreeze actions, and its harness marks batch freeze as dangerous.
- The SA alert and device pages also expose row selection with batch-oriented actions.
- DataGrid currently exposes rowSelection only as a boolean and cannot report or clear selected keys.
