# Sample Inventory ERP Project

This sample project validates the project-context layer of Ludi Design Kit. It is a `validation-sandbox`, not a source of truth for business component strategy or third-party UI foundation decisions.

Files:

- `business-context.json`: project type and scope boundary
- `prd.mdx`: structured product context
- `flows.json`: flow cards, focused on how pages connect
- `pages.json`: intent cards, pattern selection, and component plans
- `generated/`: generated output candidates
- `feedback/`: review queue for component, page, rule, and token feedback

Use it to test whether AI can move from PRD to page planning before generating UI.

Do not add new domain components from this sample. Use a real-product brief before deciding shadcn, antd, or business-specific components.
